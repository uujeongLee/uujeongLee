## 🧠 AI Projects

- **🎞️ AI-Powered YouTube Thumbnail Generator**  
  Extracted key video moments using `VideoMAE`, generated caption summaries with `BLIP` and `LLaVA`, and composed visually balanced thumbnails via automated text layouting.

- **🧑‍🎨 FACE: Facial Editing with Diffusion Transformers**  
  Collaborated on a **Purdue University joint research** to build a controllable facial editing system using `DiT` (Denoising Diffusion Transformer), conditioned on text and landmark inputs.

- **📈 AI Chatbot for the Visually Impaired**  
  Designed a voice/natural language interface using `FAISS` + `Mistral` + `RAG`, enabling real-time Q&A over stock data — enhancing accessibility for blind users.

- **📊 Indoor Scene Segmentation with PSPNet**  
  Led semantic segmentation experiments on indoor images, integrating preprocessing, model training, and evaluation.
